# Offer OS

Offer OS 是一个浏览器本地优先的求职工作台。当前第一切片提供岗位看板的持久化、仪表盘统计与投递热力图，以及本地备份和恢复。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

开发服务器启动后，在终端显示的本地地址打开应用。

## 验证与构建

```bash
npm test
npm run test:e2e
npm run build
```

`npm test` 运行单元与结构测试；`npm run test:e2e` 会在 Chromium 的 1440px、1024px 和 390px 视口中验证登录、岗位持久化和仪表盘同步；`npm run build` 生成 Vite 生产构建。

## 数据与备份

岗位、活动和第一切片的数据存放在当前浏览器的 IndexedDB 中，只存在于这个浏览器配置文件和这台设备。刷新页面不会清除数据；清除站点数据、使用隐私浏览窗口或切换浏览器则会失去这份本地数据。

请定期在应用的本地数据控制区导出备份文件，并将文件存放在你自己的可靠位置。恢复时可选择合并导入，或选择替换导入；替换前先保留一份现有导出文件，以便需要时恢复。

## 登录与安全

当前登录流程是本地演示门禁，不是云端账户、身份服务或跨设备认证。它不会把你的求职数据上传到服务器。

不要把 LLM 服务密钥或任何其他凭据提交到仓库、文档、测试样例或构建产物中。若在本地配置了模型服务，请仅按应用界面的本地保存方式使用，并在共享设备上格外谨慎。

## 当前范围

本切片迁移了岗位、活动、仪表盘和本地备份恢复的核心工作流。日历、简历、模拟面试、复盘、门户和设置中的其余模块仍由遗留实现提供，尚未迁移到新的持久化数据层；它们会继续按迁移前的行为运行，后续迁移将分模块进行。
