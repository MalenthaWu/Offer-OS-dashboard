# 仪表盘月历中心排版设计

## 目标

在不新增、删除或改写任何仪表盘板块的前提下，强化月历作为桌面端主视觉，并让右侧信息栏形成稳定、紧凑的纵向阅读顺序。

## 桌面布局

- 保留“问候区 → 四个指标卡 → 主内容区”的页面顺序。
- 四个指标卡继续单行等宽排列。
- 主内容区采用双栏：左栏为月历，右栏依次为投递热力图、下一关键时刻、接下来。
- 右栏宽度限制为 320–360px；月历使用剩余宽度。
- 主栏与右栏间距为 16px；右栏卡片纵向间距为 14px。
- 仪表盘问候区和指标区的垂直间距略微收紧，其他页面不受影响。

## 响应式布局

- 1180px 以下：右栏固定为 320px，主栏继续弹性伸缩。
- 1100px 以下：为避免月历只能显示少量日期列，改为单栏，并将月历最小画布调整为 640px；月历之后依次显示下一关键时刻、接下来、投递热力图。
- 900px 以下：沿用单栏，同时启用现有移动侧栏。
- 680px 以下：沿用现有两列指标卡和可横向滚动月历，不改变内容与交互。

## 不在范围内

- 不修改任何板块内部文案、数据、按钮或视觉样式。
- 不修改仪表盘 DOM 结构或 JavaScript 逻辑。
- 不影响岗位、简历、面试、复盘等其他页面。
